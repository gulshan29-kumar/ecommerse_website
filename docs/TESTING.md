# Testing Guide

- **Unit Testing**: Jest & React Testing Library for utility functions and UI components.
- **End-to-End Testing**: Playwright test suites for complete shopping and checkout flows.
- **Type Checking & Linting**: `next lint` and strict React 19 JSX checks.

- Wishlist buttons include aria-label for screen reader accessibility.

- Quick add buttons provide full product title context in aria-label.
